First-time GitHub setup
  1. Sign in to GitHub as an account with write access to Chrojoh/CWag-Tracker.
  2. Open GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. Create a token with resource owner Chrojoh, access to only CWag-Tracker, and repository permission Contents: Read and write. Choose an expiry date.
  4. Copy it into the field above. Never put it in a repository file, message, screenshot or shared document.

This beta uses GitHub access rather than creating a separate tracker password. An expired token can be replaced without reinstalling the tracker.
